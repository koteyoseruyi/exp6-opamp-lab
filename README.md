# 实验六 集成运算放大器的应用

在线访问：https://koteyoseruyi.github.io/exp6-opamp-lab/

根据实验六指导书与实验室实物素材制作的中文交互指导，包含：

- 六列插件板、741 模块四个信号底脚与面板 ±15 V 供电接线
- 减法器、反相加法器、实际积分器、实际微分器的 59 个分步
- ST2016 两路直流接入加法器，也可切换 DG4062 Arb → DC
- 示波器、函数发生器、双电源与万用表的相关操作
- 手动填写实测数据并导出 CSV

网页为纯静态 HTML，主要程序、照片与原理图均已内置，不依赖第三方脚本或字体。实测数据保存在访问者当前浏览器中，不提交到服务器。

## 使用

选择顶部项目，按“演示这一步”查看安装或仪器设置，再在实物上操作。模块底脚落孔是示范布局，实际按模块脚距选孔；截图遮挡部分按实验电路原理安排。教学模型读数不能代替课堂实测或教师检查。

原始课程 PDF / Word 未随公开网站发布。网页底部保留相关仪器的官方参考链接。

## 本地打开

下载 index.html 即可使用主要演示；icon.svg 是网站图标。.nojekyll 用于 GitHub Pages 静态发布。
